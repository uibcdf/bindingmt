## T0 public and record decisions

`BindingInterface.from_topomt(provider_result, *, question, participants,
grouping, analysis_name='pisa', artifact_ref=None, contexts=None, site_refs=None)`
is the explicit optional intake. Inputs are actual public `PisaOutput` or
`ProviderRun` objects, never duck-typed records or a new XML/ZIP parser. Explicit
native recovery stays `topomt.load_provider_output`/`ProviderRun.load`.

The method lazily guards/imports TopoMT through DepDigest. Its core JSON reader,
copy, summary and independent saved footprint reader do not import TopoMT,
PharmacophoreMT or the originating engine, resolve assets or perform molecular
work. Add only an optional TopoMT availability declaration; no public version
floor or installed pairing is inferred from this development source.

Experimental Interface 0.6 adds exactly one `topomt_preserved` analysis with a
bounded `topomt_observation` profile. Existing 0.1–0.5 records retain their wire
and readers. Old readers must refuse 0.6 rather than silently lose its authority.
The retained observation identifies the original run/provider/backend, complete
metadata, artifact checksum inventory, original attribution, assembly policy and
ordered findings. Finding fields, contact rows/maps, geometry availability and
original attributed measurements retain their owner meanings. No raw native ZIP
or molecular trajectory is embedded, and no duplicate topographic registry is
introduced. Known interpreted measurement values use PyUnitWizard QuantityRecord
with explicit field/unit/dimension checks; unqualified fields remain opaque JSON.

A recovered `PisaOutput`, including zero interfaces, means `completed`, with an
explicit finding list. A `ProviderRun` carrying confirmed `execution_status=failed`
and `failure_stage=analysis` means `failed`, with the original diagnostics. Other
raw evidence is `unknown`, with findings unavailable rather than fabricated empty.
No supplied analysis continues to use the existing declaration with no analyses.
Source-bound recovery/parser/integrity failure is never converted to original
scientific failure or zero. Missing external references remain readable evidence.

T0 preserves evidence only; it checks owner object/profile integrity, not live
molecular correspondence, asset availability or binding. Participants/grouping
are caller declarations, separately retained from the finding's original two
participants. Unsupported stronger assurance remains explicit. Retained hashes
identify content and do not authenticate a source or a finding.

## T1 public/portable profile decisions — fixed before implementation

`interface.recover_topomt(molecular_system, *, bundle_file, analysis_name='pisa')`
explicitly recovers a completed original analysis through its public owner,
checking the exact preserved run/context/artifact inventory. It never changes
the stored original outcome. Incomplete/corrupt/missing/wrong-context assets keep
their actual owner/I/O diagnosis. Reading the core record performs none of this.

`interface.project_reported_footprint(molecular_system, *, bundle_file,
finding_id, participant, contact_groups, analysis_name='pisa',
assurance_scope='molecular_correspondence', context_policy='require_match')`
selects an actual finding, not a completed-zero analysis without a finding.
The first profile binds two singleton declared participants to the finding's
complete original chains through public MolSysMT atom/chain queries. It uses
the unchanged complete original native MolSys and its saved reference state/frame.
It admits no transferred/edited source or inferred transformation. Repeated
owner recovery and whole-frame geometry witnesses bracket composition; unchanged
borrowed identity/state/chemistry throughout the call remains a caller precondition.

ContactFootprint experimental 0.2 contains a typed `reported_projection`, distinct
from the unchanged native 0.1 `calculation`. It retains the original observation,
exact parent/ref, selected finding/participant/groups, explicitly unit-bearing
reported distances, all witnesses and historical correspondence receipt. Source
and local axes are identical for this original-source molecular profile. The
same data-only endpoint-union helper additionally receives the separately authored
nonidentity-map/overlap control required by the plan; that is not proof of a
transferred live PISA finding. No raw XML/ZIP or molecular coordinates are embedded.

`footprint.check_context(molecular_system, *, bundle_file)` explicitly repeats
the required owner/source facts for this profile and returns a new check receipt,
without rewriting the historical footprint or gaining new originating-engine
credit. Independent 0.2 read/copy/summary remains source/asset/owner-free.
`current_finding` and unsupported group/map/assurance requests refuse before
scientific execution; no weaker success is returned silently.
